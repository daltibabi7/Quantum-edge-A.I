## Deployment
This is a static site. Deploy it with **GitHub Pages**:

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set source to `main` branch and `/` (root).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
